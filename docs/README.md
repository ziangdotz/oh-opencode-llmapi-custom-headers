## 文档约定

- “已验证”只表示在当前工作区和指定命令下执行过，不代表对其他宿主版本、其他操作系统或生产环境的保证。
- “未验证”表示本次交付明确没有执行，不能从静态检查推断通过。
- 版本号、配置 schema、插件 ID、RPC ID、Provider 前缀和 storage key 都是稳定契约；变更必须同时更新文档、测试和迁移说明。
- 所有示例中的密钥、端点和请求头均为占位值，不得直接用于生产。
