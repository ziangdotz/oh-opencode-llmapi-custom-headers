# 验证范围

目标：OpenCode 2.3.0，插件 v0.1.0，配置版本 1。

已验证的功能基线：配置与请求头校验、大小写无关合并、保存冲突/持久化失败、模型目录解析与合并、TUI 取消/删除确认、集成关联与终端缓存同步。真实宿主确认三个 exports 可识别；TUI 单命令已验证，用户已确认配置和连接成功。隔离测试确认 API key 通过 OpenCode 保存并在 Session 请求中形成 Authorization。三协议本地 HTTP 测试确认请求路径及自定义头；模拟端点返回预期 HTTP 400，不等于完整流式响应验收。

此次结构规范化已通过 npm run verify（格式、类型、10 项测试）和真实 OpenCode 2.3.0 三协议 HTTP 回归，并只读确认既有 agentrouter-openai 路由及集成保留。已检查 tarball 清单，并从最终 tgz 解包目录通过真实宿主 RPC 和三协议出站请求回归；Windows/Linux 远端 CI 未执行。

尚未完成：标题/压缩/重试专项抓包、WebSocket 实连、图片链路、所有协议完整流式响应、多个服务端实例共同写入 storage、远端 CI、独立安全审计。不能将项目规范化理解为这些验收已经通过。
