# 故障排查

| 症状               | 处理                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| 找不到命令         | 用 opencode debug paths 确认配置目录；检查 opencode.json 和 cli.json 的插件绝对路径，退出重开终端     |
| connect 找不到路由 | 主菜单刷新，然后搜索路由名；应出现 LLM API Custom Headers · 路由名；仍不出现时重启 OpenCode           |
| 模型列表为空       | 检查是否保存模型，或在主菜单发现模型；远端目录可能需要先连接密钥                                      |
| 401/403            | 检查 /connect 中活动账号、API key 权限、Base URL，以及 headers 是否覆盖了自动 Authorization/x-api-key |
| SAVE_CONFLICT      | 先保留草稿，再重新读取配置并重做修改；不强制覆盖                                                      |
| 已保存但刷新失败   | 配置已经持久化，运行菜单刷新；不要将该提示理解为保存未发生                                            |
| 未支持字段         | 查阅 CONFIGURATION.md 的迁移边界，移除或转换对应字段                                                  |

远程连接时，服务端路由必须配置于所连接的服务；本地仅加载 TUI 不能提供远程 RPC。报告问题时附 OpenCode/插件版本、操作步骤、脱敏错误和协议；不要附密钥、数据库或完整敏感请求头。
